核心原则胜率与转移池个人表现 英雄对位队内分配系列赛与示例

一、核心原则与计算流程

  • 胜负决定方向：胜方所有参赛选手身价上涨，败方所有参赛选手身价下降，个人表现不改变方向。
  • 赛前实力决定总量：按两队五名选手赛前身价总和估算胜率；强队正常取胜的变动较小，弱队爆冷取胜的变动较大。
  • 局内表现决定分配：经济、战斗、稳定性、地图资源及英雄对位数据决定队内各人分到的涨跌幅。
  • 全场严格零和：胜方总涨幅等于败方总跌幅，ΣΔPwin = −ΣΔPloss。

结算顺序：计算双方团队赛前身价 → 赛前预期胜率 → 原始转移池 → 赛制上限 → 个人表现与英雄对位修正 → 超预期指数 → 指数权重分配。

二、团队胜率与身价转移池

每队赛前总身价为五名出场选手身价之和，记为 TA、TB。赛前预期胜率：

PA = 1 / {1 + exp[−(TA − TB) / σ]}；PB = 1 − PA；σ = 5000

实际获胜方的赛前胜率记为 PW，原始转移池 Graw = 2500 × (1 − PW) P。胜者赛前胜率为 90%、50%、10% 时，原始转移分别为 250P、1250P、2250P。

例如蓝方五人各 3000P、红方五人各 4000P，则两队总身价为 15000P、20000P，蓝方预期胜率约 26.9%，红方约 73.1%。

经济与战斗

同位置经济比较：Gi = 100 × clip[2(Goldi − Goldj) / (Goldi + Goldj), −1, +1]。

战斗事件基础分：击杀 +1、助攻 +0.6、死亡 −1、完成单杀额外 +0.3、被单杀额外 −0.35。参团率 KP = (击杀 + 助攻) / 团队击杀。战斗分 Ci = 70 × clip[(Ti − Tj) / 6] + 30 × clip[(KPi − KPj) / 0.4]；T 为完整击杀事件流计算的战斗事件值。

稳定性

以同位置双方的失误差标准化为 Si。被单杀记 1.0 单位；无收益死亡记 0.6；资源前死亡额外记 0.8；120 秒内再次死亡额外记 0.5；6 分钟内再次被同一对位选手单杀额外记 0.5。无收益死亡指死亡后 20 秒内己方没有击杀或重要资源；资源前死亡指死亡后 45 秒内敌方获取重要资源。

四、英雄对位与超预期指数

英雄对位参考 OP.GG 韩服翡翠及以上分段的最新数据，只参与队内个人分配，不参与团队赛前胜率。

上路、中路、下路、辅助：QWR = (胜率 − 50%) / 5%；QLK = (对线击杀率 − 50%) / 10%；QKDA = [(KDAi / KDAj) − 1] / 0.30；对位指数 = 0.55QWR + 0.30QLK + 0.15QKDA。

打野对位指数 = 0.65QWR + 0.20QKDA + 0.15QKP。样本量修正 λ = n / (n + 200)；有效样本 n < 50 时，对位修正 E2,i = 0。

个人超预期指数 Zi = clip[(Ai − E2,i) / 100, −1, +1]。个人赛前身价差不再进入 Z，以免与团队胜率重复计算。

五、指数权重与整数分配

胜方权重 Wi = exp(βZi)，个人涨幅 ΔRi = G × Wi / ΣWj；败方权重 Wi = exp(−βZi)，个人跌幅 ΔRi = −G × Wi / ΣWj。指数权重始终大于 0，因此胜方每人上涨，败方每人下降；败方表现较差者承担更多跌幅。

来源文档在“指数化队内分配”处写 β = 1.2，但后续公式与软边界示例采用 β = 1.0。正式使用哪一个值需要明确。文档的软边界示例仅适用于 β = 1.0：权重范围为 e−1 至 e1，一人 Z = +1、其余四人 Z = −1 时，该人约分得 64.9% 的胜方转移池。

先把本局实际转移池 G 取整为 Gint，再按权重计算理论小数份额，用最大余数法分配整数。这样胜方总涨幅为 Gint，败方总跌幅为 −Gint，整数化后仍严格零和。

六、系列赛结算与文档示例

每局独立计算并即时更新身价；下一局以更新后的身价重新计算预期胜率与转移池。整轮持续检查队伍累计净变化 |C| ≤ Cmax。同方向变化若触及上限，只执行至上限；向 0 回撤时可正常执行。

例如 BO3 的上限为 2000P，前两局某队累计 +1850P，第三局再赢且原始应 +500P，则只执行 +150P；若第三局输且应 −500P，则完整执行，累计变为 +1350P。

原文测试局：蓝方五人各 3000P、红方五人各 4000P，红方获胜。红方赛前胜率约 73.1%，Graw ≈ 672.4P，BO1 实际转移 672P。蓝方五人变化依次为 −123、−140、−157、−150、−102P；红方五人依次为 +121、+143、+155、+151、+102P，两边总额均为 672P。
