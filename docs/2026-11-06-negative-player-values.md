# 负身价

- 总身价、五个位置身价及身价变化记录均允许负整数；比赛结算可以跨过 0，保留现有软边界规则。最高身价仍取五个位置的最大值，全负时最大值也为负数。
- 工资逐人以 `max(0, 身价)` 为基数计算，队伍扣薪使用相同口径，负身价不会抵减其他人的工资。分组发薪仍使用最高身价。
- 租借结算保留真实身价快照，租借费以 `max(0, 身价)` 为基数计算，各方分成最低为 0。
- 队伍总身价、联盟平均身价、加权出场身价按真实值计算，包括身价差优势折算后的负值。奢侈税仍按原阶梯规则计算，最低为 0。
- 未参赛衰减保留现有下限；低于或等于下限的位置不再衰减，也不会被抬高。

## 数据库升级

发布新版后端前，先备份数据库，再执行 `backend/src/main/resources/db/migration_negative_player_values.sql`。脚本依赖此前的位置身价及加权出场身价迁移；新建数据库也应在这些既有迁移之后执行本脚本。脚本只变更字段为有符号类型，不改写业务数据，可重复执行。

MySQL DDL 隐式提交，不能依赖事务回滚。已有负值后，不可直接回退为 `UNSIGNED`；回滚应先恢复备份或另行处理负值。
