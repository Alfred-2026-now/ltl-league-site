# 管理后台视觉统一

沿用官网 public-theme 的黑金与海克斯青配色，后台样式限定在 `.admin-site`，由 `src/styles/admin-theme.css` 提供。全部 16 个 admin HTML 页面均接入，不影响官网和用户积分兑换页。

- 桌面使用分组侧边导航，手机使用折叠菜单，支持 Escape 关闭和 aria-expanded 状态。
- 表格、表单、资产统计、图表、规则折叠面板、奖品卡片与弹窗统一配色、边框及间距。
- 原有控件 ID、接口、权限和提交逻辑保留；旧战队赛页面在对应上下文中保留导航。
- 奖品图片失败时使用已有本地 reward-placeholder.svg，避免远程占位服务重复失败。
- 赛果录入页补齐共享导航入口。

## 验证

- package.json check 中所有 JavaScript 语法检查通过，新增的 admin-nav 与修改的奖品脚本额外通过 node --check。
- 现有 8 项测试通过：`node --test tests/*.test.*`。本机 bundled Node 24 不接受旧脚本的 `node --test tests` 目录参数，因此直接指定测试文件。
- 1440px 桌面检查资产、奖品、规则参数、选手页面；390px 手机检查后台入口页面宽度，均无整页横向溢出，宽表格在容器内滚动。
- 检查资产、公告、奖品和规则的实际数据展示；验证奖品弹窗打开/取消、手机导航展开/Escape 关闭、规则折叠和隐藏编辑按钮。
